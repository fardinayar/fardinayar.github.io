SSL Depth is a comprehensive deep learning framework for self-supervised depth estimation, focusing on robust, type-safe implementation with PyTorch Lightning integration. The framework provides modular, extendable codebase with registry pattern using Python dataclasses, supporting multi-frame depth estimation capabilities and seamless integration with PyTorch Lightning for scalable training. It includes comprehensive documentation and examples, making it suitable for applications in autonomous vehicles, robotics, computer vision, and augmented reality. The project follows a clean modular structure with configs, scripts, datasets, losses, models, trainers, and utilities, contributing to advancing self-supervised depth estimation through production-ready implementation and type-safe interfaces.

Viser is an innovative educational web-based application designed for visualizing and editing vehicle frames and sensor extrinsics. The tool provides an interactive environment for understanding complex sensor configurations in autonomous vehicles and robotics systems, featuring real-time 3D visualization of vehicle frames, support for various sensors including cameras and LiDARs, tools for editing sensor extrinsics, and live global pose readouts with local sensor-space adjustments. This educational tool enhances learning by providing visual understanding of abstract sensor concepts, interactive hands-on experience with sensor configurations, and immediate visualization of configuration changes, making it valuable for autonomous vehicle development, robotics education, research projects, industry training, and system integration planning.
